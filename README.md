## SEO & Accessibility

- `robots.txt` + `sitemap.xml` for Google indexing
- `<link rel="canonical">` to prevent duplicate content
- Open Graph + Twitter Card meta tags
- JSON-LD structured data (Schema.org `Person`)
- Skip-to-content link for keyboard navigation
- `aria-label` on all interactive elements
- `aria-expanded` on mobile nav toggle
- `autocomplete` on form fields
- Semantic HTML landmarks (`header`, `main`, `section`, `footer`)
- `prefers-reduced-motion` media query support

## Local Development

No build step needed — just open in a browser:

```bash
git clone https://github.com/adilth/portfolio.git
cd portfolio
# Open index.html in your browser, or use a local server:
npx serve .
```
